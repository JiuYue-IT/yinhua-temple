# 直接问签接入与双层输出

2026-10-01。接续 docs/08 的检查结论，当前完整前端已经接入直接问签。

## 当前体验

许愿池填写一段心事或愿望（最多 400 码点）→ 点击“收好这个愿”时立即 POST 创建会话并在后台生成 → 投币、过渡、礼佛照常进行 → 正殿抽签展示总结 → 菩提树下打开果实展示详细回应 → “存此一念”确认收据。

总结和详情在**同一次模型请求**中一起生成，互相对应；抽签和打开果实都不会再次调用模型。
提前生成可以利用中间的体验时间，但不能保证模型一定在得签前完成。若正殿仍未 ready，会等待真实生成结果；错误时提供重试、回许愿池或明确标注的预置案例。
没有假进度，也不会把固定文本冒充真实生成。

## 两个独立维度

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| experience | direct / explore | 直接问签 / 原来的情境探索，省略时默认 explore 以兼容旧请求 |
| mode | live / preset | 真实模型 / 预置案例 |

完整前端固定提交 experience=direct，没有新增直接问签/探索的模式按钮。
explore 仍保留四项输入、故事、A/B、签文和收据的完整后端逻辑。
预置案例按钮只在错误恢复时出现，必须显示“预置案例演示”，不是根据用户输入生成。

## 输入契约

```json
{
  "requestId": "UUID，同一次提交的网络重试复用",
  "experience": "direct",
  "mode": "live",
  "wish": {
    "concern": "我希望把项目做好，也担心能力和时间不够。",
    "background": null,
    "chosenPath": null,
    "unchosenPath": null,
    "priority": null
  }
}
```

只有 concern 必填（1—400 码点）。可选信息分别限制 400 / 100 / 100 / 150 码点，空白归一为 null。
前端暂不呈现可选字段，后台提示词明确禁止把缺失信息编造成事实。
direct 不接收探索 input；explore 不接收 wish；preset 不接收用户输入。

## 输出契约

快照新增 experience、wish、reading；direct 时 input、story、selectedOptionId 为 null。
generating 时 reading 为 null；ready 后一次填充两个对象：

| 分组 | 字段 | 展示位置 | 长度上限 |
| --- | --- | --- | ---: |
| summary | title | 正殿签题 | 20 |
| summary | verse | 正殿短偈 | 60 |
| summary | message | 正殿总结 | 100 |
| detail | understanding | 菩提：照见心事 | 300 |
| detail | possibility | 菩提：可能的走向 | 300 |
| detail | suggestion | 菩提：如何安放 | 300 |
| detail | nextStep | 菩提：现实中的一小步 | 150 |
| detail | basis | 菩提：依据和信息边界 | 200 |

长度按 Unicode 码点计数。模型生成结果同时由 Schema 和后台字段校验约束，缺字段或超长进入 AI_FORMAT_ERROR，不截断、不编造补齐。
动态文本通过 textContent 展示。详细卡片可滚动阅读，避免长内容挤出画面。

## 状态与设备

direct：generating → ready → POST /sign → sign_drawing → sign_ready → POST /receipt → complete。
无需 /choice，调用 /choice 会返回 409。只有 sign_ready 才能确认直接问签收据。
生成时不发送硬件 DRAW / STORY，避免在许愿池提前摇动实物签筒；正殿 /sign 发送 SIGN，再由 SIGN_RESULT 表示签文就绪。
幂等 requestId、reset 失效代号、总超时、迟到结果丢弃继续复用原会话实现。

父页面的 api.js 管理会话与后台轮询，iframe 切换不会停止生成，也不会每章重置后端。
重新填写、完成后重玩才重置。浏览器刷新后读取保存的 id 并向服务器查询；服务器重启后 404 会引导回许愿池。
收据新增 experience / concern；未提供已选、未选道路时相应字段为 null，不伪造道路。
“存此一念”将总结和行动建议保存到收据，无需再填第二份表单。

## 启动

```powershell
Set-Location D:\minicamp-dev\server
.\mvnw.cmd spring-boot:run
```

打开 http://localhost:8080/。后台默认托管 front_all/因花寺-完整游戏；没有 npm 构建步骤。
AI 连接沿用 server/.env 的现有配置，没有把密钥写到前端。
也可以先启动后台，再双击前端启动预览.cmd；serve.py 会把 /api 代理到本机 8080，并支持滚动视频 Range。
