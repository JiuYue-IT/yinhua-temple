## 当前接入缺口

| 位置 | 当前行为 | 接入所需改变 |
| --- | --- | --- |
| 根入口 / continuation.js | iframe 切换与完成消息，没有后端 reset / health | 在完整体验开始和重玩时统一管理 reset；父页面管理会话，避免每次 iframe 加载清空会话 |
| original/chapters/wish/main.js | 一个最多 50 字的愿望，只存在内存中 | 增加 background、chosenPath、unchosenPath、priority；创建 live 或 preset 会话，保存 id / 快照并轮询 |
| original/chapters/hall/index.html | 固定第七签与固定解读 | 展示 story 和 A/B 结果 / 回望；调用 choice、sign，等待 sign_ready 后展示返回签文 |
| original/chapters/bodhi/index.html | 固定“一念”文本；点击存念只发 bodhi-complete 消息 | 使用 snapshot.sign；编辑 insight / nextStep，调用 receipt，确认 complete 后结束与下载 |
| serve.py | 随机端口静态预览，没有 /api 代理 | 采用后端同源托管，或迁移旧版代理；当前预览服务器直接访问 /api 不会调用后端 |

输入限制：背景 400 字、已选道路 100 字、未选道路 100 字、在意目标 150 字；收据编辑各 200 字。
一个 50 字愿望不能直接作为 CreateSessionRequest.input。
成功响应直接返回 SessionSnapshot，没有 data 外层；接口字段以 `contracts/types.ts` 和现行后端源码为准。
后端只保留一个活动会话；轮询需处理 error / 404 / 取消，真实 AI 的等待时限应大于后端任务时限（默认 65 秒）。

## 同源启动方式

从项目根目录执行：

```powershell
$env:WEB_DIST='../front_all/因花寺-完整游戏/'
Set-Location server
.\mvnw.cmd spring-boot:run
```

随后打开 `http://localhost:8080/` 与 `http://localhost:8080/api/health`。
这能证明静态托管与 API 可共同提供服务，仍需完成上述业务迁移才能让页面真正使用后端。
