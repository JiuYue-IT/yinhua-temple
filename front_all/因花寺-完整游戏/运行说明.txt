因花寺 S01–S15 完整最新版

1. 右键压缩包，选择“全部解压”。
2. 先在项目 server 文件夹运行 mvnw.cmd spring-boot:run，或由 IntelliJ 启动 ServerApplication。
3. 打开 http://localhost:8080/；也可在前端文件夹双击“启动预览.cmd”，通过预览代理连接后端。
4. 运行期间保留后端及预览窗口。

本机已安装 Python。其他电脑需要 Python 3；无需 npm 编译，游戏素材和配乐已打包。
不要在压缩包内直接打开 index.html，单独打开只会显示启动指引。
